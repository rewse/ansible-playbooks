# fox への Rex 導入 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** fox に Rex を apt で入れ、tats の Rex サーバーを常時動かし、iPhone の Rex の公開鍵を tats の `authorized_keys` に載せる。

**Architecture:** 新しい `rex` ロールに `apt` と `server` の 2 コンポーネントを置き、`home-primary.yml` のサービス階層（`nvr` と `syslogd` の間）に加える。ubuntu ロールの `user` コンポーネントは、ubuntu ユーザーの `authorized_keys` を `slurp` で読み、`ubuntu_admin_extra_authorized_keys` をつないだ内容を `copy` の `content` で tats に書く。

**Tech Stack:** Ansible（`ansible.builtin.deb822_repository`、`get_url`、`template`、`apt`、`command`、`getent`、`stat`、`systemd_service`、`slurp`、`copy`）、pytest + unittest、PyYAML、Jinja2。

**Spec:** `docs/superpowers/specs/2026-11-29-rex-design.md`

## Global Constraints

- 作業は worktree `.worktrees/rex`（ブランチ `feat/rex`）で行う。playbook は `direnv exec /Volumes/ExternalHD/git/ansible-playbooks ansible-playbook ...` で実行する。
- apt のチャンネルは `preview`。鍵 URL は `https://pkgs.superlogical.com/rex/keys/rex-archive-keyring.gpg`、置き場所は `/etc/apt/keyrings/rex-archive-keyring.gpg`、リポジトリ URI は `https://pkgs.superlogical.com/rex/apt`、コンポーネントは `main`。
- pin ファイルは `/etc/apt/preferences.d/rex`。レコードはこの順で `Package: rex` / `Pin: origin pkgs.superlogical.com` / `Pin-Priority: 1001`、次に `Package: rex` / `Pin: release *` / `Pin-Priority: -1`。
- dpkg のアーキテクチャ名は `aarch64` → `arm64`、`x86_64` → `amd64`。
- `ubuntu_admin_extra_authorized_keys` が空または未定義のとき、tats の `authorized_keys` は `/home/ubuntu/.ssh/authorized_keys` と 1 バイトも違わない。
- `mode` はダブルクォートの 4 桁 8 進数、タスク名は `<component> | <命令形>`、変数は `rex_` / `ubuntu_`、register は `__rex_` / `__ubuntu_` で始める。
- `command` には理由のコメントと `changed_when` を付ける。
- テンプレートは `{{ ansible_managed | comment }}` で始める。

## Review Focus

- ubuntu ユーザーの `authorized_keys` が改行で終わっていないときに追加の鍵を足すと、最後の既存の鍵と新しい鍵が 1 行につながる。改行を補ってから足す（Task 1 のテスト `test_extra_keys_start_on_their_own_line`）。
- pin の 2 レコードの順序が逆だと、すべての `rex` が -1 になって何も入らない（Task 2 のテスト `test_pin_prefers_rex_and_bans_every_other_rex`）。
- 初回の check mode では Rex がまだ入っておらず、ユーザーサービスもない。`server` のタスクが失敗せずに飛ぶこと（Task 3 のテスト `test_service_task_skips_in_check_mode_before_install`）。
- `systemctl --user` は `XDG_RUNTIME_DIR` がないと tats のユーザーマネージャーに届かない（Task 3 のテスト `test_user_scope_tasks_reach_the_user_manager`）。
- linger を有効にする前にユーザーサービスを作ると、ログアウトでサーバーが止まる（Task 3 のテスト `test_linger_comes_before_server_install`）。

- [ ] **Step 1: 失敗するテストを書く**

`tests/test_ubuntu_authorized_keys.py` に、ヘルパー `task(name: str) -> dict` と `render(base: str, extra: list[str] | None) -> str` を書く。`task` は `roles/ubuntu/tasks/user.yml` を PyYAML で読み、名前でタスクを返す。`render` は `user | Write authorized_keys for admin` の `vars` を先に描画してコンテキストに加え、そのあと `ansible.builtin.copy.content` を Jinja2 で描画する。Environment には `filters["b64decode"] = lambda s: base64.b64decode(s).decode()` を足す。コンテキストには `__ubuntu_authorized_keys={"content": base64.b64encode(base.encode()).decode()}` を渡す。`extra` が `None` のときは `ubuntu_admin_extra_authorized_keys` を渡さない（Jinja2 の既定の `Undefined` のまま）。

```python
BASE = "ssh-ed25519 AAAA1 mac\nssh-ed25519 AAAA2 ubuntu\n"

def test_without_extra_keys_the_file_equals_ubuntu_keys(self):
    self.assertEqual(render(BASE, None), BASE)
    self.assertEqual(render(BASE, []), BASE)
    self.assertEqual(render("ssh-ed25519 AAAA1 mac", []), "ssh-ed25519 AAAA1 mac")

def test_extra_keys_follow_ubuntu_keys(self):
    self.assertEqual(
        render(BASE, ["ssh-ed25519 BBBB1 iphone", "ssh-ed25519 BBBB2 ipad"]),
        BASE + "ssh-ed25519 BBBB1 iphone\nssh-ed25519 BBBB2 ipad\n",
    )

def test_extra_keys_start_on_their_own_line(self):
    self.assertEqual(
        render("ssh-ed25519 AAAA1 mac", ["ssh-ed25519 BBBB1 iphone"]),
        "ssh-ed25519 AAAA1 mac\nssh-ed25519 BBBB1 iphone\n",
    )

def test_keys_are_read_from_ubuntu_and_written_to_admin(self):
    read = task("user | Read authorized_keys of ubuntu")
    self.assertEqual(read["ansible.builtin.slurp"]["src"], "/home/ubuntu/.ssh/authorized_keys")
    self.assertEqual(read["register"], "__ubuntu_authorized_keys")
    write = task("user | Write authorized_keys for admin")["ansible.builtin.copy"]
    self.assertEqual(write["dest"], "/home/{{ admin_user }}/.ssh/authorized_keys")
    self.assertEqual(write["mode"], "0600")
    self.assertEqual((write["owner"], write["group"]), ("{{ admin_user }}", "{{ admin_user }}"))
    self.assertNotIn("remote_src", write)
```

def test_linger_comes_before_server_install(self):
    names = [t["name"] for t in yaml.safe_load((ROLE / "tasks" / "server.yml").read_text())]
    self.assertLess(names.index("server | Enable linger for admin"), names.index("server | Install user service"))
    linger = task("server.yml", "server | Enable linger for admin")
    self.assertEqual(linger["ansible.builtin.command"]["creates"], "/var/lib/systemd/linger/{{ admin_user }}")

def test_server_install_runs_once_as_admin(self):
    install = task("server.yml", "server | Install user service")
    self.assertEqual(install["become_user"], "{{ admin_user }}")
    self.assertEqual(install["ansible.builtin.command"]["cmd"], "rex server install")
    self.assertEqual(install["ansible.builtin.command"]["creates"], "/home/{{ admin_user }}/{{ rex_server_unit }}")
    self.assertIn("changed_when", install)

def test_user_scope_tasks_reach_the_user_manager(self):
    for name in ("server | Install user service", "server | Start user service"):
        t = task("server.yml", name)
        self.assertEqual(
            t["environment"]["XDG_RUNTIME_DIR"],
            "/run/user/{{ ansible_facts['getent_passwd'][admin_user][1] }}",
        )

def test_service_task_skips_in_check_mode_before_install(self):
    start = task("server.yml", "server | Start user service")
    unit = start["ansible.builtin.systemd_service"]
    self.assertEqual((unit["name"], unit["scope"], unit["state"], unit["enabled"]), ("rex", "user", "started", True))
    self.assertEqual(start["become_user"], "{{ admin_user }}")
    self.assertEqual(start["when"], "not ansible_check_mode or __rex_server_unit.stat.exists")

`server.yml` のタスクは次の順に置く。

- `server | Check user service`: `stat` で `/home/{{ admin_user }}/{{ rex_server_unit }}` を調べる。register は `__rex_server_unit`。
- `server | Start user service`

`main.yml` に `server.yml` の import を足し、タグは `rex_server` にする。
